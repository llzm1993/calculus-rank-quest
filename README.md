# 微积分晋级

账号版请使用支持 Web Locks 的新版 Edge、Chrome、Firefox 或 Safari。同一浏览器中的同一账号一次只开放一个学习标签页，避免离线草稿互相覆盖；不同设备之间的存档冲突会提示选择保留的版本。

从青铜到王者的一元微积分闯关游戏：7 个段位、21 关、84 道题，包含概念学习、提示解析、错题复习、知识手册、切线与定积分互动演示。

项目提供两个独立入口：

| 入口 | 用途与存档 |
| --- | --- |
| `index.html` | 注册登录的云端版，需要真实的 Supabase 项目、数据库与公开配置。未配置时显示设置提示，不提供游客入口。 |
| `微积分晋级.html` | 本地离线单文件，无需注册或联网，沿用当前浏览器中的旧版本地进度。通过 `npm run build:offline` 生成，不随 GitHub Pages 发布。 |

云端版上线步骤见 [DEPLOY.md](DEPLOY.md)。GitHub Pages 只托管网页，Supabase 提供邮箱注册、身份验证和数据库；代码准备完成不代表已经创建服务或发布到你的账号。

## 玩法

- 七个段位：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀 → 王者。
- 每关先学概念，再答 4 题；答对至少 3 题得 2 星并解锁下一关，全对得 3 星。
- 每完成一个段位的 3 关，解锁下一段位；第 21 关是最终挑战。
- 答对 +10 XP，答错 +2 XP。段位由通关决定，重复挑战保留最佳成绩。
- 每题有提示和解析，无时间限制。错题自动收集，复习答对后移出错题本。
- 学习档案展示段位、关卡、正确率、星星、近七天答题数和连续学习天数。
- 桌面答题可用数字键 1–4 选择答案，Enter 操作当前聚焦的按钮。

适合开始学习一元微积分的学生。先修知识包括代数运算、常见函数和基本三角函数；三角函数均按弧度制。

## 注册、保存与教师查看

云端版用昵称、邮箱和密码注册，按邮件提示验证邮箱后登录。支持退出登录和找回密码。密码由 Supabase Auth 处理，不写入游戏进度表。正式面向学生开放前，项目管理者需要配置自己的 SMTP 发信服务。

答题过程自动保存，也可点击「保存进度」。已同步的段位、关卡、错题及未完成题目随账号保存，另一台设备登录同一账号即可继续。页面会分别显示等待同步、保存成功或失败；退出前确认状态为「进度已保存到账号」。网络中断时会尽可能缓存尚未同步的本机进度，连接恢复后可重试；本机存储被禁用时页面会明确提示。

本机缓存按 Supabase 项目和用户隔离，云端通过登录身份与数据库行级权限（RLS）隔离。切换账号不会把前一个人的存档上传给后一个人。离线版的旧存档也不会自动合并到云端账号。

若不同设备同时学习造成版本冲突，页面会暂停覆盖并要求选择保留云端版本或本机版本，不会静默覆盖另一台设备的新记录。「清除进度」需要确认；云端版清除的是当前账号的学习记录，离线版清除的是当前浏览器的离线记录。

项目管理者可在 Supabase SQL Editor 给自己的用户 UID 授予教师权限；具体 SQL 见 [DEPLOY.md](DEPLOY.md)。教师登录后可查看学生昵称、当前段位、通关数量、星星、经验及最近同步时间。普通学生无法自行授予教师权限，也无法读取其他学生的学习记录。

## 本地开发

使用 Node.js 22 LTS 或更新的受支持 LTS 版本：

```powershell
npm ci --ignore-scripts
npm test
Copy-Item config.example.js config.js
# 在 config.js 中填写你自己的 Supabase URL 和 publishable key
npm start
```

打开 `http://127.0.0.1:4188/`。首次运行先按照 [DEPLOY.md](DEPLOY.md) 在 Supabase 执行 `supabase/schema.sql` 并配置邮箱登录。数据库权限验收脚本是 `supabase/verify.sql`。

发布构建从 `SUPABASE_URL` 和 `SUPABASE_PUBLISHABLE_KEY` 环境变量读取配置：

```powershell
npm run build
```

生成的 `dist/` 只包含账号版所需静态文件。没有配置或填入 `secret` / `service_role` 密钥时构建会失败。GitHub 工作流读取仓库的同名 Variables，不读取被 Git 忽略的本地 `config.js`。

生成离线单文件：

```powershell
npm run build:offline
```

随后双击 `微积分晋级.html`。离线存档仅保存在同一个浏览器和同一文件地址的 localStorage 中；换浏览器、换地址或清除浏览器数据可能无法恢复。它与云端版以及 `localhost` / `127.0.0.1` 地址的存档互相独立。

## 主要文件

| 文件 | 作用 |
| --- | --- |
| `index.html`、`styles.css`、`app.js` | 云端入口、响应式界面与游戏交互 |
| `curriculum.js`、`engine.js` | 课程题库、段位与答题存档逻辑 |
| `accounts.js`、`cloud.js`、`cloud-sync.js` | 注册登录、云端接口、缓存与同步冲突处理 |
| `config.example.js` | 公开配置示例；复制成 `config.js` 用于本地调试 |
| `supabase/schema.sql`、`supabase/verify.sql` | 数据库、权限、接口与 SQL 验收 |
| `build-site.cjs`、`.github/workflows/pages.yml` | 受限发布构建与 GitHub Pages 工作流 |
| `build.cjs`、`serve.cjs` | 离线打包与本地预览 |
| `tests/` | 游戏、云端、数据库与发布构建测试 |
| `vendor/supabase.js` | 官方 Supabase 客户端固定版本，本地加载，无运行时 CDN |

## 使用边界

GitHub Pages 的代码和题目是可以下载的静态资源。登录界面用于正常的注册使用流程；学生数据的实际访问权限由 Supabase Auth 和 RLS 执行。课堂进度由浏览器提交，适合学习记录，不是防作弊考试成绩。需要题目保密或可信考试判分时，应另外建设服务端判题系统。

尚未配置真实服务时，可以运行本地与模拟测试，但邮箱送达、实际跨设备同步及正式网址仍需部署后验收。
